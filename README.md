# Redes-infraestructura-proyectos
Colección de diseños de red, topologías de infraestructura y simulaciones de entornos corporativos.
### 🏥 Diseño de Red Hospitalaria de Alta Disponibilidad
* **Descripción:** Simulación de una infraestructura de red para un entorno hospitalario. El diseño garantiza la conectividad crítica entre áreas médicas, administrativas y de emergencias, priorizando la seguridad de los datos de los pacientes.
* **Tecnologías:** Cisco Packet Tracer, VLANs (Segmentación por departamentos), DHCP, Enrutamiento Inter-VLAN, ACLs (Seguridad para proteger servidores médicos).
